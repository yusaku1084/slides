# 2026-10 GitHub Universe 2026 LT（5分）

「AIがコードを書く、その先へ。GitHub Universe 2026 から見る開発の未来」

- `slides.md` — スライド本体。pushするとCIでビルド・公開される
- `faq.md` — 出典・技術的な補足・質疑用メモ

## メモ

- 各スライドのHTMLコメントがトーク原稿（目安秒数付き）。Marpのプレゼンターノートとして表示される
- 原稿は約1,450字・約4分50秒（1分あたり約300字で計算）
- 山場は Slide 5「AIの承認は、AIの修正で外れる」。公式の2つの仕様（Agent Merge は修正コミットを追加する／新しいコミットで Copilot の承認は外れる）を組み合わせた説明なので、`faq.md` の注意書きも参照
- 図はHTMLで組んでいるため、ビルド・プレビューには HTML の有効化が必要（CIは `--html` 付きでビルド済み。VS Code では `markdown.marp.enableHtml` を ON）
- デザインはこのLT用に白×青のシンプルなスタイル（リポジトリ標準の紫グラデーションとは別）
- 元はHTMLスライド（frontend-slides で作成）からMarpに変換したもの
